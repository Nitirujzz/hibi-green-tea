# Hibi Brand Story: shot list
37.3 s · 90 bpm · 56 beats (1 beat = 0.667 s) · format: 9x16 (1080x1920)
Music: synthesized lofi, F major; drums come in at beat 16 (the "drop") · VO: none (on-screen Thai type carries the story)

Palette: dark green `#1F3D24` (ink / dark backgrounds), matcha `#9CC65B` (the single accent), cream `#F5F0E4` (paper), gold `#E6C47E` (Capy, warm details).
Type: Display = **Mitr** (headlines), UI = **Prompt** (body, branches). `日々` uses a Japanese serif (Shippori Mincho), only inside the logo mark.
Characters + props: drawn as vector shapes in code (see `docs/modelsheet.png`). No photos and no generated raster images.
**AI disclosure:** a small line "ภาพประกอบสร้างด้วย AI" stays at the top of the safe area the whole time, and is larger on the end card.
**No health claims:** the copy only talks about quality, price, care and every day. Nothing about health, antioxidants, energy or "good for you".
