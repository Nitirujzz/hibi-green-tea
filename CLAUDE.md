# Hibi Matcha Cafe — guidance for content work

Before any content task (posts, carousels, reels, captions, scheduling), read the knowledge base:
`docs/content-plan/knowledge/README.md` — brand facts & menu, owner feedback rules, content formulas,
production playbook (Higgsfield / ffmpeg / audio / motion graphics), Buffer IDs & rules, tool limits.

Key rules (details in the knowledge base):
- Use official Hibi & Capy character sheets (`docs/content-plan/campaigns/mbti-carousel/characters/`).
- Never state unconfirmed facts listed under "เรื่องที่ยังรอยืนยัน" in `knowledge/01-brand-facts.md`.
- Reels: hook within 3 s, no dead air, soft background sound under VO, text inside safe zone (x 70–950, y 190–1440).
- Buffer: TikTok = notification scheduling; assets via commit-pinned raw.githubusercontent URLs (repo must stay public until posts publish).
- After new feedback or a better technique, update the matching file in `docs/content-plan/knowledge/`.
