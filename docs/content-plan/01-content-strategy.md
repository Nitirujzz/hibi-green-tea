## 0. Brand Foundation (สรุปสั้นให้ทุกคนพูดเรื่องเดียวกัน)

| หัวข้อ | รายละเอียด |
|---|---|
| ชื่อแบรนด์ | **Hibi (日々) = "ทุก ๆ วัน"** |
| Brand Idea | **"มัทฉะดี ๆ ที่ดื่มได้ทุกวัน — ชิลแบบคาปิบาร่า"** |
| Positioning | ร้านมัทฉะญี่ปุ่นแท้ที่ *เข้าถึงง่าย* ไม่ต้องเป็นสายลึกก็ดื่มสนุก — คุณภาพระดับพรีเมียม แต่บรรยากาศสบาย ๆ |
| Brand Character | **Hibi-Capy** — คาปิบาร่าใจเย็น เป็นมิตรกับทุกคน ชอบออนเซ็น ชอบมัทฉะ ช้าแต่ชัวร์ ไม่รีบ ไม่ตัดสินใคร |
| Brand Promise | ทุกแก้ว = มัทฉะคัดเกรดจากญี่ปุ่น ตีสดทุกแก้ว + ช่วงเวลาพักใจเล็ก ๆ ในวันวุ่นวาย |
| Tone of Voice | อบอุ่น · ขี้เล่นนิด ๆ · รู้จริงแต่ไม่อวดรู้ · พูดแบบเพื่อน ไม่ใช่ครู |
| Tagline (เสนอ) | TH: **"ชิลทุกวัน กับมัทฉะของ Hibi"** / EN: **"Every day, a little calm."** |

### ทำไมต้องมี Hibi-Capy เป็นแกนกลาง
1. **คาปิบาร่า = สัญลักษณ์ของความชิล** ซึ่งตรงกับ insight คนเมือง "อยากพัก แต่ไม่มีเวลา" → แก้วมัทฉะคือการพัก 15 นาที
2. คาแรกเตอร์ทำให้ **คอนเทนต์ความรู้ที่ดูยาก (เกรดมัทฉะ, วิธีชง) กลายเป็นเรื่องน่ารัก แชร์ง่าย**
3. เป็น **สินทรัพย์ที่สาขาไหนก็ใช้ได้** → ทำให้ 5 สาขาดูเป็นแบรนด์เดียวกัน แต่แต่งตัว Capy ต่างกันตามสาขาได้
4. ต่อยอดเป็น Merch / สะสมแต้ม / Photo spot ในร้าน → สร้าง UGC

## 1. Objective Framework

### 1.1 จาก Business Goal → Content Objective

```
BUSINESS GOAL        เพิ่มยอดขายรวม 5 สาขา + เพิ่มลูกค้าประจำ
      │
MARKETING OBJ.       ① คนรู้จัก Hibi มากขึ้นในรัศมี 5 กม. ของแต่ละสาขา
                     ② คนเลือก Hibi เมื่อนึกถึง "มัทฉะ"
                     ③ ลูกค้ากลับมาซ้ำ + บอกต่อ
      │
CONTENT OBJ.         Awareness · Consideration · Conversion · Loyalty (ดู 1.2)
```

### 1.2 Content Objectives (SMART) — 90 วัน

| # | Objective | ทำไปเพื่อ | KPI หลัก | เป้า 90 วัน* |
|---|---|---|---|---|
| O1 | **Brand Awareness** — ให้ Hibi-Capy เป็นที่จดจำ | คนเห็น Capy แล้วนึกถึง Hibi | Reach, Video views (3s/ThruPlay), Follower growth | Reach สะสม `[ฐาน×3]`, Follower +25% |
| O2 | **Consideration** — ให้คนรู้ว่า Hibi "มัทฉะดีจริง" และอยากลอง | สร้างเหตุผลในการเลือก | Saves, Shares, Profile visit, Avg. watch time | Save+Share rate ≥ 3% ของ reach |
| O3 | **Store Visit / Conversion** — พาคนเข้า 5 สาขา | ยอดขายต่อสาขา | คลิกเส้นทาง (Google Maps), โทร, คูปองที่ถูกใช้แยกสาขา, ออเดอร์ Delivery | คูปอง Redeem `[x]` ใบ/สาขา/เดือน, Direction clicks +30% |
| O4 | **Loyalty & Advocacy** — ลูกค้ากลับมาและบอกต่อ | ลดต้นทุนหาลูกค้าใหม่ | LINE OA friends, Repeat rate (stamp), UGC/Tag, รีวิว Google ★ | LINE +`[x]` คน, UGC ≥ 60 ชิ้น, ★ ≥ 4.6 ทุกสาขา |

\* ใส่ตัวเลขฐาน (baseline) เดือน ต.ค. 2026 ก่อนเริ่ม แล้วตั้งเป้าเป็น % เพิ่ม

### 1.3 Guiding Principles (กฎ 5 ข้อของทุกโพสต์)
1. **1 โพสต์ = 1 Objective = 1 CTA** — ห้ามทั้งขายทั้งสอนทั้งแจกในโพสต์เดียว
2. **Capy ปรากฏอย่างน้อย 60% ของคอนเทนต์** (ตัวเต็ม / สติกเกอร์มุม / เสียงพากย์)
3. **ทุกโพสต์ตอบได้ว่า "ลูกค้าได้อะไร"** (รู้เพิ่ม, ขำ, ได้ส่วนลด, ได้ที่เที่ยว)
4. **ระบุสาขาเสมอเมื่อพูดเรื่องโปร/เมนูเฉพาะสาขา** — กันลูกค้าไปผิดสาขา
5. **Hook ภายใน 1–3 วินาทีแรก / บรรทัดแรก** เสมอ

## 2. Content Funnel

```
            ┌───────────────────────────────────────────┐
 TOFU 40%   │  AWARENESS  "รู้จัก Hibi + รัก Capy"         │  Reels/TikTok สั้น, มีม Capy, Trend, ASMR ตีมัทฉะ
            └───────────────────────────────────────────┘
              ┌───────────────────────────────────────┐
 MOFU 30%     │ CONSIDERATION  "Hibi มัทฉะดีจริง"        │  ความรู้มัทฉะ, เมนูเจาะลึก, เบื้องหลัง, รีวิว, FAQ
              └───────────────────────────────────────┘
                ┌───────────────────────────────────┐
 BOFU 20%       │ CONVERSION  "ไปสาขาไหนดี / ซื้อเลย"   │  แนะนำสาขา, โปร, เมนูใหม่+ราคา, Delivery, คูปอง
                └───────────────────────────────────┘
                  ┌───────────────────────────────┐
 LOYALTY 10%      │ LOYALTY  "กลับมาอีก + บอกต่อ"    │  สมาชิก LINE, Stamp, UGC repost, Community, Merch
                  └───────────────────────────────┘
```

| Stage | คำถามในใจลูกค้า | งานของคอนเทนต์ | Format ที่เวิร์ก | CTA | KPI |
|---|---|---|---|---|---|
| **TOFU** | "อะไรน่ารัก ๆ เนี่ย?" | หยุดนิ้ว / สร้างความจำ | Reels/TikTok 7–20s, Meme, Trend, Capy POV | ติดตาม / แชร์ให้เพื่อน | Reach, Views, Follow |
| **MOFU** | "มัทฉะร้านนี้ต่างจากร้านอื่นยังไง?" | ให้เหตุผล + ความเชื่อมั่น | Carousel ความรู้, Reels 30–60s, เบื้องหลัง, รีวิว | Save ไว้ก่อนไป / คอมเมนต์ถาม | Save, Share, Watch time |
| **BOFU** | "ไปสาขาไหน? ราคาเท่าไร? มีโปรไหม?" | ตัดสินใจ + ลด friction | โพสต์สาขา, เมนู+ราคา, คูปอง, Story link, GBP post | กดเส้นทาง / สั่ง Delivery / แอด LINE | Clicks, Redeem |
| **LOYALTY** | "กลับไปอีกดีไหม? มีอะไรใหม่?" | ให้รางวัล + ให้มีส่วนร่วม | LINE broadcast, UGC repost, Member only, Poll | สะสมแต้ม / แท็ก @hibi | Repeat, UGC, Review |

**การเชื่อม Funnel (Retargeting loop):** คนดูวิดีโอ TOFU ≥ 50% → ยิงแอด MOFU (Carousel ความรู้) → คน Engage/Save → ยิงแอด BOFU แยกตามรัศมีสาขา → คนแอด LINE → Loyalty (ดูรายละเอียดใน 03-ads-brief)

### 3.1 6 Pillars (ครบตามโจทย์)

| Pillar | สัดส่วน | เนื้อหา | ตัวอย่างหัวข้อ |

| **รวม** | **100%** | | |

## 7. Workflow & Governance

```
จันทร์  Raw Content Kit จาก 5 สาขา → ทีมกลาง
อังคาร  วางแผนสัปดาห์ถัดไป + เขียนแคปชัน (ใช้ template ใน 02)
พุธ     ส่ง Brief กราฟิก/ตัดต่อ (ใช้ template ใน 03)
พฤหัส   ตรวจ (Brand check list ด้านล่าง) → อนุมัติ
ศุกร์   ตั้งเวลาโพสต์ + ตั้งแอด
ทุกวัน  ตอบคอมเมนต์/DM ภายใน 2 ชม. (เวลาเปิดร้าน), รีวิว Google ภายใน 24 ชม.
สิ้นเดือน รายงาน KPI ต่อ Objective/Pillar/สาขา → ปรับสัดส่วน
```

- [ ] ระบุ Objective + Funnel stage ได้
- [ ] Hook 1–3 วินาทีแรก / บรรทัดแรก
