**ข้อกำหนด Google Ads**
- 1:1 ต้องไม่ต่ำกว่า 128×128 (แนะนำ 1200×1200)
- 4:1 ต้องไม่ต่ำกว่า 512×128 (แนะนำ 1200×300)
- ไฟล์ PNG/JPG ไม่เกิน 5 MB
- บางตำแหน่งตัดภาพเป็นวงกลม จึงวางมาร์กให้สูงราว 58% ของภาพ อยู่ตรงกลาง

**ที่มา**
- มาร์กและ “Hibi 日々” ลอกลายเป็นเวกเตอร์ (potrace) จากโลโก้เดิมในหน้า Google Ads → `src/vectorize.py`
- ต้นฉบับความละเอียดต่ำ ขอบจึงอาจไม่เนียน 100% → **ถ้ามีไฟล์ AI/SVG ต้นฉบับจากดีไซเนอร์ ให้ใช้ไฟล์นั้นแทน** แล้วรัน `src/build_ads_logos.py` ใหม่
