## ทำไมต้องทำ
- **Coconut cloud** = น้ำมะพร้าวใสบนน้ำแข็ง + มัทฉะคลาวด์โฟมลอยด้านบน เป็นไวรัลบน TikTok · มัทฉะเย็นคือออร์เดอร์หลักของกลุ่มอายุต่ำกว่า 35
- เล่าให้ตรงคำที่คนค้นหา (“coconut cloud”) → คนที่เห็นเทรนด์รู้ว่าสั่งได้ที่ Hibi

## ลุคของเครื่องดื่มในคลิป (ปรับตาม feedback)
- น้ำมะพร้าว **ใส** บนน้ำแข็ง · **ไม่มีสีชมพู** · ไม่มีชั้นนม
- แก้วพลาสติกใส **ทรงตัว U ก้นโค้งมน**
- มัทฉะคลาวด์ **ชั้นเรียบ ๆ แบบปกติ** เสมอขอบแก้ว (ไม่บีบเป็นเกลียว) + สายมัทฉะค่อย ๆ ไหลลงในน้ำใส
