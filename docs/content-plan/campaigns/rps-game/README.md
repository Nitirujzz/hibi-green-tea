# เกม “เป่ายิ้งฉุบกับ Hibi & Capy” (เวอร์ชันทดลอง)

> หน้าเกม: `/game` · หน้าพนักงาน: `/game/admin` · ภาพหน้าจอ: `screens_share.jpg`, `screens_animated.jpg`, `screens_flow.jpg`, `screens_win.jpg` · คลิปสาธิต: `demo_animated.mp4`
> โค้ด: `app/game/` (หน้าเว็บ) · `app/api/game/[...slug]/route.ts` (API ทั้งหมดรวมไว้ไฟล์เดียว — บน Vercel แบบไม่มีฐานข้อมูลจะได้แชร์หน่วยความจำเดียวกัน) · `src/lib/game/` (กติกา รางวัล OTP ฐานข้อมูล) · ภาพตัวละคร `public/game/*.webp` (Higgsfield อ้างอิงชีตทางการ)

## กติกา
1. ลงทะเบียนด้วยเบอร์มือถือ + ยินยอม PDPA → รับ OTP 6 หลัก (หมดอายุ 5 นาที · ขอใหม่ได้ทุก 60 วิ · ไม่เกิน 5 ครั้ง/วัน · กรอกผิดได้ 5 ครั้ง)
2. รอบ 1 เจอ **Hibi** → ชนะได้ **ส่วนลด 15%**
3. รอบ 2 เจอ **Capy** → ชนะทั้งคู่ได้ **ส่วนลด 50%** (คูปองรอบแรกถูกอัปเกรดเป็น 50%) · แพ้ Capy ยังเก็บรางวัลรอบแรกไว้
4. เสมอเล่นใหม่ได้ · เล่นได้ **วันละ 1 ครั้งต่อเบอร์** · คูปองใช้ได้ 14 วัน ทุกสาขา
5. พนักงานเปิด `/game/admin` ใส่ PIN → ตรวจรหัสคูปอง → กด “ใช้สิทธิ์” (ใช้ซ้ำไม่ได้)

## แอนิเมชัน
- ตัวละครเคลื่อนไหวจริง: คลิปวนลูปจาก Higgsfield Seedance (`public/game/loop_{both,hibi,capy}.webm/.mp4` + ภาพ poster) ในหน้าแรก/หน้าเจอคู่แข่ง/หน้าเลือกท่า — ใช้ไฟล์ต้นฉบับใน `anim_src/` · เบราว์เซอร์ที่เล่นวิดีโอไม่ได้จะแสดงภาพนิ่งแทนอัตโนมัติ
- framer-motion: ตัวหนังสือเด้ง · ใบชา/หัวใจ/ประกายลอยพื้นหลัง · ฟองคำพูดพิมพ์ทีละตัว · ปุ่มเต้น · ตัวละครเด้งตามจังหวะ “เป่า ยิ้ง ฉุบ” · มือพุ่งเข้าชนกัน 💥 · ผู้ชนะกระโดด/ผู้แพ้ส่ายหน้า · คูปองพลิกเข้า + แสงวิ่ง · พลุตอนชนะทั้งคู่ · มือถือสั่นตามจังหวะ (Android)

## เสียง & เพลง (แต่งเอง ไม่ติดลิขสิทธิ์)
- `public/game/sfx/`: เพลงพื้นหลังวนลูป 20 วิ (`bgm.mp3` อูคูเลเล่ + กล็อคเกนสปีล 96 BPM, ต่อลูปเนียน) · เสียงกดปุ่ม · จังหวะ “เป่า/ยิ้ง/ฉุบ” · มือชนกัน · ชนะ (กริ๊งไล่โน้ต) · แพ้ (ว้าว ๆ ตลก) · เสมอ (ดึ๋ง) · ได้คูปอง (ประกาย) · ชนะทั้งคู่ (แฟนแฟร์ + เพลงพื้นหลังเบาลงชั่วคราว)
- สร้างใหม่ได้ด้วย `audio_src/make_sounds.py` · ระบบเสียง `app/game/sound.ts` (เปิดเพลงเมื่อแตะครั้งแรก — เบราว์เซอร์บังคับ · ปุ่ม 🔊/🔇 มุมขวาบน จำค่าไว้ในเครื่อง)

## แชร์ผลการเล่น
- ปุ่ม “แชร์ผลให้เพื่อน 📣” หลังจบเกม (ทั้งชนะและแพ้ — แพ้ก็แชร์ได้แบบตลก “ใครจะมาแก้แค้นให้?”)
- สร้างการ์ดขนาดสตอรี่ 1080×1920 ในเครื่องลูกค้า (`app/game/share.ts`) — **ไม่มีรหัสคูปอง** (กันคนอื่นเอาไปใช้) · ตัวอย่าง `share_card_example.png`
- มือถือที่รองรับ: เปิดเมนูแชร์ของเครื่อง (ส่งรูป + ข้อความ + ลิงก์ ไป IG/FB/LINE/TikTok ได้เลย) · ไม่รองรับ: แผ่นแชร์ — บันทึกภาพ, Facebook, LINE, X, คัดลอกลิงก์
- ลิงก์แชร์ `/game?ref=share` มีภาพตัวอย่างลิงก์ (`public/game/og.jpg`) — ตั้ง `NEXT_PUBLIC_SITE_URL` เป็นโดเมนจริงตอน deploy

## ความเป็นธรรม & โอกาสชนะ (สำคัญต่องบส่วนลด)
- ผลออกที่เซิร์ฟเวอร์แบบสุ่มเท่ากัน 1/3 ทุกท่า — ลูกค้าโกงจากหน้าเว็บไม่ได้ และร้านไม่ได้ “ปรับให้แพ้”
- เพราะเสมอแล้วเล่นใหม่: **ชนะ Hibi ≈ 50% · ชนะทั้งคู่ ≈ 25% ของผู้เล่น** (ทดสอบจำลอง 60 คน ได้ 15 คนชนะ 50%)
- จึงมี **เพดานรางวัลต่อวัน**: ส่วนลด 50% = 20 ใบ/วัน · รางวัลรอบแรก = 200 ใบ/วัน (แก้ได้ใน env) — ทดสอบแล้ว ครบ 20 ใบระบบหยุดแจกทันทีและแจ้งผู้เล่นก่อนเริ่ม
- ถ้าอยากให้ได้ยากขึ้นอย่างเป็นธรรม: เพิ่มรอบที่ 3 (≈12.5%) หรือ “ต้องชนะ 2 ใน 3 ตาในแต่ละรอบ”

## เปิดใช้จริง — ต้องตั้งค่า
| ตัวแปร | ใช้ทำอะไร |
|---|---|
| `GAME_SECRET` | คีย์เซ็นคุกกี้/OTP (สุ่มยาว ๆ · บังคับใน production) |
| `GAME_OTP_MODE` | `demo` (แสดงรหัสบนจอ — ทดสอบเท่านั้น) / `twilio` |
| `TWILIO_ACCOUNT_SID`, `TWILIO_AUTH_TOKEN`, `TWILIO_FROM` | ส่ง SMS จริง (หรือเพิ่มผู้ให้บริการไทย เช่น ThaiBulkSMS ใน `src/lib/game/otp.ts`) |
| `GAME_ADMIN_PIN` | PIN พนักงาน (โหมด demo ใช้ 1234) |
| `GAME_WIN1_LABEL` (ค่าเริ่ม “ส่วนลด 15%”), `GAME_WIN1_PERCENT` (15), `GAME_WIN1_DAILY_CAP`, `GAME_WIN2_DAILY_CAP`, `GAME_COUPON_DAYS` | รางวัลและเพดาน |
| `NEXT_PUBLIC_SITE_URL` | โดเมนจริง (ใช้กับภาพตัวอย่างลิงก์ตอนแชร์) |
| `DATABASE_URL` | Postgres (ตาราง `game_players`, `game_otps`, `game_plays`, `game_coupons` ใน `prisma/schema.prisma` → `npm run db:push`) · ไม่ตั้ง = เก็บในหน่วยความจำ (หายเมื่อรีสตาร์ต — ใช้ทดลองเท่านั้น) |
