# เกม “เป่ายิ้งฉุบกับ Hibi & Capy” (เวอร์ชันทดลอง)

> หน้าเกม: `/game` · หน้าพนักงาน: `/game/admin` · ภาพหน้าจอ: `screens_share.jpg`, `screens_animated.jpg`, `screens_flow.jpg`, `screens_win.jpg` · คลิปสาธิต: `demo_animated.mp4`
> โค้ด: `app/game/` (หน้าเว็บ) · `app/api/game/[...slug]/route.ts` (API ทั้งหมดรวมไว้ไฟล์เดียว — บน Vercel แบบไม่มีฐานข้อมูลจะได้แชร์หน่วยความจำเดียวกัน) · `src/lib/game/` (กติกา รางวัล OTP ฐานข้อมูล) · ภาพตัวละคร `public/game/*.webp` (Higgsfield อ้างอิงชีตทางการ)

## กติกา
1. ลงทะเบียนด้วยเบอร์มือถือ + ยินยอม PDPA → รับ OTP 6 หลัก (หมดอายุ 5 นาที · ขอใหม่ได้ทุก 60 วิ · ไม่เกิน 5 ครั้ง/วัน · กรอกผิดได้ 5 ครั้ง)
2. **กรอกเลขท้ายใบเสร็จ 5 หลัก + วันที่ในใบเสร็จ** ก่อนเล่น (เจ้าของสั่ง 6 พ.ย.) — 1 ใบเสร็จเล่นได้ 1 ครั้ง (เลขท้าย+วันที่ซ้ำ ระบบไม่รับ) · วันที่ต้องไม่เกินวันนี้ และย้อนได้ 1 วัน (`GAME_RECEIPT_MAX_AGE_DAYS`, 0 = เฉพาะวันนี้)
3. รอบ 1 เจอ **Hibi** → ชนะได้ **ส่วนลด 15%**
4. รอบ 2 เจอ **Capy** → ชนะทั้งคู่ได้ **ส่วนลด 35%** (คูปองรอบแรกถูกอัปเกรดเป็น 35%) · แพ้ Capy ยังเก็บรางวัลรอบแรกไว้
5. เสมอเล่นใหม่ได้ · เล่นได้ **วันละ 1 ครั้งต่อเบอร์**
6. **เงื่อนไขคูปอง** (แสดงบนคูปอง หน้าแรก และหน้าพนักงาน): ใช้ได้ในการมาครั้งถัดไป · ภายใน 30 วัน · เฉพาะหน้าร้าน · ใช้กับยอดมูลค่าไม่เกิน 1,000 บาทต่อบิล
7. พนักงานเปิด `/game/admin` ใส่ PIN → ตรวจรหัสคูปอง (เห็นเลขท้าย+วันที่ใบเสร็จที่ใช้เล่น) → กด “ใช้สิทธิ์” · ระบบไม่ให้ใช้ในวันเดียวกับที่ได้คูปอง (“ครั้งถัดไป” — ปิดได้ด้วย `GAME_COUPON_SAME_DAY=yes`) · ใช้ซ้ำไม่ได้

## ความเป็นธรรม & โอกาสชนะ (สำคัญต่องบส่วนลด)
- ผลออกที่เซิร์ฟเวอร์เท่านั้น — ลูกค้าโกงจากหน้าเว็บไม่ได้ · เสมอ 1/3 ของตา (เล่นใหม่) เหมือนเกมจริง
- **โอกาสชนะที่ร้านกำหนด (เจ้าของสั่ง 6 พ.ย.)**: ชนะ Hibi **2/3** (`GAME_HIBI_WIN_CHANCE`) · ชนะ Capy **1/3** (`GAME_CAPY_WIN_CHANCE`)
- ผลรวม: **ได้ส่วนลด 15% ≈ 2 ใน 3 ของผู้เล่น (ชนะ Hibi) · ชนะทั้งคู่ได้ 35% ≈ 2/9 ≈ 22%** — ทดสอบจำลอง 300 คน ชนะ Hibi 69%
- ปรับโอกาสได้ที่ env ของ Netlify โดยไม่ต้องแก้โค้ด (เช่น 0.5 = สุ่มเท่ากัน)
- **เพดานรางวัลต่อวัน**: ส่วนลด 35% = 20 ใบ/วัน · รางวัลรอบแรก = 200 ใบ/วัน (แก้ได้ใน env) — ทดสอบแล้ว ครบ 20 ใบระบบหยุดแจกทันทีและแจ้งผู้เล่นก่อนเริ่ม
- ถ้าอยากให้ได้ยากขึ้นอย่างเป็นธรรม: เพิ่มรอบที่ 3 (≈12.5%) หรือ “ต้องชนะ 2 ใน 3 ตาในแต่ละรอบ”

## เปิดใช้จริง — ต้องตั้งค่า
| ตัวแปร | ใช้ทำอะไร |
|---|---|
| `GAME_SECRET` | คีย์เซ็นคุกกี้/OTP (สุ่มยาว ๆ · บังคับใน production) |
| `GAME_OTP_MODE` | `demo` (แสดงรหัสบนจอ — ทดสอบเท่านั้น) / `twilio` |
| `TWILIO_ACCOUNT_SID`, `TWILIO_AUTH_TOKEN`, `TWILIO_FROM` | ส่ง SMS จริง (หรือเพิ่มผู้ให้บริการไทย เช่น ThaiBulkSMS ใน `src/lib/game/otp.ts`) |
| `GAME_ADMIN_PIN` | PIN พนักงาน (โหมด demo ใช้ 1234) |
| `GAME_WIN1_LABEL` (ค่าเริ่ม “ส่วนลด 15%”), `GAME_WIN1_PERCENT` (15), `GAME_WIN2_LABEL` (“ส่วนลด 35%”), `GAME_WIN2_PERCENT` (35), `GAME_WIN1_DAILY_CAP`, `GAME_WIN2_DAILY_CAP`, `GAME_COUPON_DAYS` (30) | รางวัลและเพดาน |
| `GAME_HIBI_WIN_CHANCE` (2/3), `GAME_CAPY_WIN_CHANCE` (1/3) | โอกาสชนะแต่ละรอบ |
| `GAME_COUPON_MAX_BILL` (1000), `GAME_COUPON_SAME_DAY` (`no`), `GAME_RECEIPT_MAX_AGE_DAYS` (1) | เงื่อนไขคูปอง/ใบเสร็จ |
| `NEXT_PUBLIC_SITE_URL` | โดเมนจริง (ใช้กับภาพตัวอย่างลิงก์ตอนแชร์) |
| `DATABASE_URL` | Postgres (ตาราง `game_players`, `game_otps`, `game_plays` (+ เลขท้าย/วันที่ใบเสร็จ), `game_coupons` ใน `prisma/schema.prisma` → `npm run db:push`) · ไม่ตั้ง = เก็บในหน่วยความจำ (หายเมื่อรีสตาร์ต — ใช้ทดลองเท่านั้น) |
