### อะไรที่ต่างจากโพสต์ต้นฉบับ
- **เปิดโพสต์:** ใช้ Hibi กับ Capy ชวนมาเป็น “Matcha Friends” แทนหัวข้อประกาศรับสมัครทั่วไป
- **การเรียงเนื้อหา:** แบ่งเป็น “เราดูแลคุณยังไง / สิ่งที่อยากได้จากคุณ” แทนรายการข้อ ๆ แบบเดิม
- **ไอเดียตั้งต้น:** เพิ่มไอเดียคอนเทนต์ที่ผูกกับแคมเปญของเราเอง (Small Moments / 1 แก้ว หลายมุม)
- **ค่าตอบแทน:** ตั้งชื่อระดับ (Micro / Mid / Rising / Macro) และเขียนหมายเหตุด้วยคำของเราเอง
- **ไทม์ไลน์:** เขียนเป็นเส้นเวลาบรรทัดเดียว แทนรายการข้อ ๆ
- **วิธีสมัคร:** รับทั้ง DM และคอมเมนต์ และให้ส่ง 3 อย่าง (ช่วยคัดคนง่ายขึ้น)
- **คำว่า “ของฝาก”:** ไม่ใช้ เพราะ Hibi ยังไม่ได้ยืนยันว่ามีชุดของฝาก
