## แนวคิด
ชื่อซีรีส์มาจากคำบนชีต Hibi: **“Small Moments, Big Happiness”**
- เล่าเรื่องเล็ก ๆ ที่คู่รักเจอทุกวัน
- Hibi สดใส ขี้ลังเล · Capy ใจเย็น ช่างสังเกต
- มีมัทฉะอยู่ในชีวิตคู่แบบเป็นธรรมชาติ ไม่ขายของตรง ๆ
- แต่ละตอนยาว 20–25 วิ แบ่งเป็น 4 ช่วง:
  1. Hook: สถานการณ์ที่ทุกคู่เคยเจอ
  2. อีกคนทำเรื่องเล็ก ๆ ที่น่ารัก
  3. อีกคนเขินหรือซึ้ง
  4. การ์ดปิดท้าย: ประโยคความรัก + ชวนแท็ก
- เสียง: เพลงอูคูเลเล่/lo-fi เบา ๆ · ไม่มีเสียงพากย์ · บทพูดเป็นบับเบิลสั้น ๆ
