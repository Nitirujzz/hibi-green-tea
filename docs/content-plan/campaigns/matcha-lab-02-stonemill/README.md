## สคริปต์ VO (Teleprompter)
```
[01] หินโม่หมุนหนึ่งชั่วโมง ได้มัทฉะแค่ราวสี่สิบกรัม
[02] ทำไมถึงช้าขนาดนี้? มาส่องกัน

[04] ใส่ลงรูกลางหินโม่ทีละน้อย
[05] ใบชาจะค่อย ๆ เดินจากกลางไปขอบหิน ผ่านร่องที่สลักไว้ ละเอียดขึ้นเรื่อย ๆ
[06] ที่ต้องหมุนช้า เพราะถ้าเร็ว แรงเสียดทานจะทำให้ร้อน สีเขียวและกลิ่นหอมจะเสียไป
[07] ผงที่ได้ละเอียดราวห้าถึงสิบไมครอน เล็กกว่าเส้นผมของเราหลายเท่า
[08] สี่สิบกรัม ชงได้ราวยี่สิบถ้วยเท่านั้น

[10] หนึ่งชั่วโมง สี่สิบกรัม ห้าถึงสิบไมครอน นี่คือความช้าที่ตั้งใจ

```

## ต้องเช็กก่อนผลิต
- 🟡 ตัวเลข 30–40 ก./ชม. และ 5–10 ไมครอน มาจากผู้ผลิตหินโม่/ร้านชา (ไม่ใช่งานวิจัย) → ใช้ “ราว/ประมาณ” เสมอ
- 🟡 ช็อต 6 (หมุนช้ากันร้อน ถนอมสี/กลิ่น) มีแหล่งเดียว · ช็อต 7 เส้นผมเป็นความรู้ทั่วไป ไม่ใส่ตัวเลข
- ✅ ช็อต 8: ภาพในคลิปมี 20 ถ้วยพอดี (ประกอบแถวใหม่) · “~20 ถ้วย” = 40 ก. ÷ ~2 ก./ถ้วย
- ❌ ไม่อ้างว่าร้านใช้มัทฉะโม่หิน/จากแหล่งไหน (ยังรอยืนยัน) · ช็อต 5, 7 ติดป้าย “ภาพจำลอง”
- ช็อต 9 ใช้ภาพจริงจากบรีฟ LAB-PHOTO ของ Year แทนได้เมื่อถ่ายเสร็จ
