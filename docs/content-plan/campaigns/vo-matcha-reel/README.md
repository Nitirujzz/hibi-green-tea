## ปรับเสียง (v2 — แก้ dead air / ไม่ลื่นหู)
- ทำใหม่จากไฟล์ดิบ: ลด noise เบา ๆ (ไม่ใช้ gate แรง → ไม่มีเสียงขาด ๆ หาย ๆ) · de-esser ลดเสียง ส/ซ แหลม · ลดเสียงอู้ 250 Hz · เพิ่มความอุ่น 140 Hz · เพิ่มความชัด 3.5 kHz · เพิ่มความใส 10 kHz
- **ปรับระดับเสียงให้เท่ากันทุกประโยค** (dynamic normalizer + compressor) → ไม่มีช่วงเบา/ดังสลับ
- **ตัด dead air**: ช่องว่างระหว่างคำเหลือ 0.06 วิ · ระหว่างประโยค 0.16 วิ · ก่อนขึ้นข้อใหม่ 0.30 วิ (ตัดออกรวม ~33 วิ ตรวจแล้วไม่มีคำพูดหลุด) · ไม่มีช่วงเงียบเกิน 0.35 วิ ตลอดคลิป
- เร่งจังหวะพูด 1.1× แบบคงโทนเสียง (rubberband) → ฟังกระฉับกระเฉงขึ้น
- **Sound background นุ่ม ๆ (v3)** แต่งและสังเคราะห์เอง ไม่มีลิขสิทธิ์ใคร (`src/build/ambient.py` → `src/ambient_bed.m4a`): pad อุ่น ๆ + เปียโนไฟฟ้าเล่นโน้ตไล่เบา ๆ + เบสต่ำ · 80 BPM · **ไม่มีกลอง** · มี reverb ให้ฟังฟุ้งนุ่ม
  - เว้นช่วงความถี่เสียงพูด (1–4 kHz) และตัดเสียงแหลม → ไม่กลบเสียงพากย์
  - เบากว่าเสียงพากย์ ~10 dB (bed −24 LUFS / voice −14 LUFS) · หลบเสียงพากย์แค่ ~3 dB แบบช้า ๆ → ได้ยินต่อเนื่องตลอด ไม่วูบวาบ · เฟดเข้า-ออกหัวท้าย
  - (เพลง lo-fi มีกลองของ v2 เก็บไว้ที่ `src/music_bed.m4a` / `music.py` ถ้าอยากได้แบบคึกคักกว่า)
- เสียงเอฟเฟกต์: ป๊อปตอนการ์ดขึ้น · วูบตอนเปลี่ยนข้อ
- Loudness: **−14 LUFS · True peak −2.8 dBTP**
- ภาพ: ช็อตที่ยาวเกิน ~3 วิ มี jump-cut ซูมกระแทกกลางช็อต → ภาพเปลี่ยนทุก 1.5–3 วิ
