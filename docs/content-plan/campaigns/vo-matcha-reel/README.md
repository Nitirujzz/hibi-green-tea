## ปรับเสียง
- high-pass 85 Hz / low-pass 13 kHz · ลด noise (afftdn) + noise gate ช่วงเงียบ · ลดเสียงอู้ 230 Hz · เพิ่มความชัด 3.2 kHz · ลดเสียงฟ่อ 7.5 kHz · compressor
- Loudness ตามมาตรฐานโซเชียล: **−13.4 LUFS · True peak −2.7 dBTP**
- เสียงเอฟเฟกต์เบา ๆ: “ป๊อป” ตอนการ์ดเด้งขึ้น + “วูบ” ตอนเปลี่ยนข้อ (สังเคราะห์เอง ไม่ติดลิขสิทธิ์) · **ยังไม่ใส่เพลง** → เลือกเพลงในแอปตอนโพสต์ ตั้งเสียงเพลงให้เบา (~10–15%)
