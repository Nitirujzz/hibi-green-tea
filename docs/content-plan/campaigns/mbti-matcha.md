## 1. ภาพรวม

| หัวข้อ | รายละเอียด |
|---|---|
| Pillar / Funnel | P1 Hibi-Capy + P2 Menu / **TOFU (แชร์)** → BOFU (มาสั่งแก้วของตัวเอง) |
| เป้าหมาย | Shares, คอมเมนต์บอก MBTI, แท็กเพื่อน · รอง: คนมาร้านแล้วสั่ง "แก้วของฉัน" |
| ทำไมคนจะแชร์ | **Identity** (“นี่มันฉัน”) + **Tag** (“นี่มันแกเลย”) + เล่าเรื่องตัวเองในคอมเมนต์ |
| ทำไมคนจะเซฟ | ใช้เป็น “คู่มือสั่ง” ครั้งหน้า: แต่ละบุคลิกมีสูตรสั่ง (ร้อน/เย็น · หวาน % · ขนมคู่) |

| ช่องทาง | IG Carousel · TikTok Photo mode + คลิป POV · FB Album · IG Story Quiz |

**หลักคิด:** ไม่สร้างเมนูใหม่ 16 แก้ว — ใช้ **เมนูจริง 4 ฐาน** แล้วให้แต่ละบุคลิก “สั่งต่างกัน” (อุณหภูมิ, ความหวาน, ขนมคู่, พฤติกรรมตอนสั่ง) → ร้านทำได้จริงทุกแก้ว และได้ดันขนมไปด้วย

| กลุ่ม | แก้วฐาน | ทำไม | Capy ประจำกลุ่ม |

| **NT นักวิเคราะห์** (INTJ INTP ENTJ ENTP) | **Clear Matcha (มัทฉะใส)** | ชอบของแท้ ไม่ปรุง อยากเข้าใจรสจริง | Capy ใส่แว่น ถือคลิปบอร์ด |
| **NF นักการทูต** (INFJ INFP ENFJ ENFP) | **Asanoka × Coconut** | หอมดอกไม้ ละมุน มีเรื่องราว | Capy มีดอกไม้บนหัว (ข้างถ้วย) |
| **SJ ผู้พิทักษ์** (ISTJ ISFJ ESTJ ESFJ) | **Matcha Latte** | คลาสสิก ไว้ใจได้ สั่งแบบเดิมทุกครั้ง | Capy ใส่ผ้ากันเปื้อน ถือแก้วเรียบร้อย |
| **SP นักสำรวจ** (ISTP ISFP ESTP ESFP) | **[เมนู Limited ประจำเดือน]** | ชอบของใหม่ ลองก่อนคิดทีหลัง | Capy ใส่หมวก ถือกล้อง |

## 6. วัดผล + ต่อยอด

| ตัวชี้วัด | ดูอะไร |
|---|---|
| Shares ÷ Reach | ตัวหลักของชิ้นนี้ — เทียบกับโพสต์ Capy อื่นในเดือน |
| คอมเมนต์ที่บอก MBTI / แท็กเพื่อน | นับเพื่อดูว่ากลุ่มไหนมีคนมากสุด |
| Saves | ถ้าสูง = คนใช้เป็นสูตรสั่งจริง → ทำโปสเตอร์หน้าร้าน |

**ต่อยอดถ้าได้ผล**
1. ทำทีละกลุ่มเป็นซีรีส์ 4 โพสต์ (เจาะลึก NT / NF / SJ / SP)
2. Story รีโพสต์คอมเมนต์ “Capy จัดแก้วให้คุณ” 1–2 วัน
3. หน้าร้าน: ป้ายเล็ก “บอก MBTI แล้วรับสูตรสั่งของคุณ” (ถ้าร้านพร้อม — ไม่ต้องมีส่วนลด)
4. นับกลุ่มที่คอมเมนต์มากสุด → ทำโพสต์ประกาศ “MBTI ที่รักมัทฉะที่สุดของ Hibi คือ…”
