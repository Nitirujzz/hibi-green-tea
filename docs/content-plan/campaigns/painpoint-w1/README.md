## โครงคลิป
**P1 (7 ช็อต):**
1. หน้าเหย (hook)
2. 2 ถ้วย: แก้วไหนขม?
3. ① น้ำเดือด → ใช้ 70–80°C
4. ② ไม่ร่อน → ร่อนก่อน
5. ③ ตีวน → ตีตัว M 15–20 วิ
6. ยิ้ม: ลองลาเต้หวาน 3–5g ก่อน
7. คำถาม 1 / 2 / 3

**P4 (4 ช็อต):**
1. 6 แก้วเรียงกัน (hook)
2. ป้ายระดับหวานเด้งทีละแก้ว 0 · 3 · 5 · 8 · 10 · 15g (ชื่อระดับตามเมนูจริง)

4. คำถาม: สั่งกี่กรัม?
