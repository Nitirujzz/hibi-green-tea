# 🍵 Lifestyle Minimal: ทิศทางคอนเทนต์ใหม่ (18 พ.ย. 2026)

> Feedback: “อยากปรับ Contents ให้มี Lifestyle แบบนี้ สวยงาม มีความ Minimal”
> ภาพอ้างอิง: `reference/ig_reference_piperlimz.png` (โพสต์ “สินค้า 1 อย่าง เล่าได้หลายมุม”)

## ทำไมภาพอ้างอิงถึงได้ผล
1. **สินค้าเดียว เล่า 9 มุม** ทั้งแก้ว มือที่ถือ ผิวโฟม การเทนม คน/ชุด และแชต → feed ดูเป็นชุดเดียวกัน แต่ไม่ซ้ำ
2. **เขียวมัทฉะเป็นสีเดียวที่สด** ส่วนอื่นเป็นขาว ครีม เทา ดำ → ภาพสะดุดตาใน feed
3. **ตัวหนังสือน้อยมาก**: serif ตัวเล็ก ภาษาอังกฤษ 2–6 คำ เป็นมุก/ความรู้สึก ไม่ใช่โฆษณา
4. **พื้นที่ว่างเยอะ** (negative space) + แสงธรรมชาติ → ดูแพง น่าเซฟ
5. **ขายตัวตน (identity)** ไม่ได้ขายเมนู: “ฉันเป็นคนแบบนี้” → คนอยากแชร์ อยากรีโพสต์

## กติกาภาพ Hibi Lifestyle Minimal
- **สี:** เขียวมัทฉะ = จุดเด่นเดียว · พื้นขาว/ครีม/ไม้โอ๊กอ่อน/คอนกรีตเทา · ❌ ไม่ใส่สีจัดอื่น
- **แก้วจริงของร้าน:** แก้วพลาสติกใสทรง U · โลโก้ Hibi หันออกเล็กน้อยพอเห็น ไม่ต้องตรงหน้า
- **ตัวหนังสือ:** serif บางและเล็ก (อังกฤษสั้น ๆ) วางมุมบนหรือล่าง · ภาษาไทยใส่ใน caption แทน
- **แสง:** แสงธรรมชาติจากหน้าต่าง/กลางแจ้ง มีเงานุ่ม ๆ · ❌ ไม่ใช้แฟลช
- **ข้อมูลบนภาพต้องจริง:** ตัวเลือกที่โชว์ (oat milk / 3g / extra ice) ต้องเป็นตัวเลือกที่ร้านมีจริง
  - Oat +20.- · ระดับหวาน 0–15g → ดู `knowledge/01-brand-facts.md`
- **ภาพ AI = ภาพตัวอย่างอารมณ์เท่านั้น** ตอนลงจริงให้ถ่ายแก้วจริงของร้าน (กฎเจ้าของร้าน: ใช้รูปจริงของสินค้า)

## วางลงแผนยังไง
- **สัดส่วนใหม่ใน feed:** Lifestyle Minimal ~40% · ความรู้ (Matcha Lab) ~25% · Hibi & Capy ~20% · โปร/เมนู ~15%
- **วางกริด 3 ช่อง:** ให้แถวเดียวกันมีทั้งภาพสว่าง/ใกล้/ไกล เช่น [พื้นขาว · คน · มาโคร] สลับกันไป
