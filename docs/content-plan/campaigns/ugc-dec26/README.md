# 📱 UGC v2 (26 พ.ย.): สร้าง “โมเมนต์ที่อยากถ่ายเอง” ในร้าน
> Feedback v1: “ยังไม่ถูกใจ” → v1 ให้ลูกค้าทำงาน (ถ่าย ตัดต่อ ตามกติกา) แลกของรางวัลเล็ก
> v2: ร้านสร้างเซอร์ไพรส์ที่ลูกค้า**อยากหยิบมือถือขึ้นมาถ่ายเอง** แล้วค่อยชวนแท็ก

1. **Mood Cup: บาริสต้าวาดหน้า Hibi/Capy ตามอารมณ์คุณ**
   - ลูกค้าบอกอารมณ์วันนี้ (เหนื่อย/ฟิน/อกหัก/รับปริญญา) → บาริสต้าวาดหน้า Hibi หรือ Capy ด้วยปากกาบนแก้ว
   - คลิปตอนเปิดดูแก้ว = รีแอ็กชันจริง · ต้นทุนแค่ปากกา
2. **Capy หายไปไหน? (ล่าหาตุ๊กตา Capy ในร้าน)**
   - ตุ๊กตา Capy 1 ตัว/สาขา ซ่อนจุดใหม่ทุกวัน · ร้านโพสต์คำใบ้ตอนเช้า
   - คนเจอถ่ายคลิป “เจอแล้ว!” → รับของ · พาคนเข้าร้านจริง
3. **หนวดมัทฉะ (#HibiMustache)**
   - เมนูท็อปโฟมนม (Velvet) จิบแล้วเกิดหนวดฟองโดยไม่ตั้งใจ → มุมกระจก + ป้าย “ถ่ายหนวดก่อนเช็ด”
   - ง่ายที่สุด · ตลก · ถ่ายเองแน่นอน
4. **มุมนั่งกับ Hibi & Capy ตัวใหญ่**
   - ตุ๊กตา/สแตนดี้ขนาดคนนั่งข้างได้ + เบาะคริสต์มาส
   - จุดถ่ายรูปคือสิ่งที่ทำให้คาเฟ่ได้ UGC มากที่สุดแบบไม่ต้องขอ
5. **ข้อความลับใต้แก้ว**
   - ทุกแก้วมีสติกเกอร์ใต้ก้นแก้ว 1 ใน 12 ข้อความจาก Hibi & Capy (กำลังใจ/คำทำนายปีใหม่) → คลิป “เปิดดูก้นแก้ว”
   - ให้รางวัลเมื่อสะสมครบชุด ไม่ใช่สุ่มของรางวัลใหญ่ (เลี่ยงกฎหมายจับรางวัล)

## 1) #HibiOrderForMe: “สั่งให้แฟนโดยไม่ถาม” ⭐ แนะนำ
- **วิธีเล่น:**
  - คนหนึ่งสั่งเมนูให้อีกคน (แฟน/เพื่อน/แม่) โดยไม่ถาม รวมระดับหวานด้วย
  - ถ่ายตอนยื่นแก้วให้ → อีกฝ่ายจิบแล้วตอบว่า “ถูกใจไหม” (✅ / ❌)
- **ทำไมได้ผล:** ต่อยอดจาก Small Moments EP1 “จำได้ด้วย?!” · รีแอ็กชันจริงตลกและซึ้ง · คนดูอยากลองกับคนของตัวเอง
- **Hook ตัวอย่าง:** “สั่งมัทฉะให้แฟนโดยไม่ถาม… รอดไหม?”

## 2) Funky Hibi Matcha Drop: คลิปเปลี่ยนฉากตามเพลง
- **ใช้เพลงแบรนด์:** ช่วง 2:12–2:24 ที่มีจังหวะดรอป
  - ก่อนดรอป: วันธรรมดาเหนื่อย ๆ (หน้างอ/โต๊ะทำงาน)
  - **ตรงดรอป:** ตัดไปถือแก้ว Hibi ยิ้ม + ฉากร้าน
- **เผยแพร่เสียงจากบัญชีร้าน:** ร้านโพสต์คลิปต้นแบบก่อน → เสียงจะขึ้นเป็น “original sound – hibimatchacafe” ให้คนกดใช้ต่อได้
- **ทำไมได้ผล:** ทำง่าย ถ่าย 2 ช็อต · ทุกคลิปที่ใช้เสียงนี้วนกลับมาที่บัญชีร้าน
- ⚠️ ต้องยืนยันว่าร้านมีสิทธิ์ใช้เพลงนี้เชิงพาณิชย์ (ถ้าสร้างด้วย AI ให้ดูเงื่อนไขแพ็กเกจของเครื่องมือนั้น)

## 3) #HibiWhiskChallenge ออนไลน์ (Stitch / Duet)
- **คลิปเปิด:** บาริสต้าตีมัทฉะ 10 วิ แล้วพูด “เก่งกว่าพี่ไหม? Stitch มาเลย”
- **ลูกค้าเล่น:** ตีเองที่บ้านหรือที่ร้าน แล้ว Stitch โชว์ระดับฟองตาม Foam Chart
- **ใช้คู่กับกิจกรรมหน้าร้าน** (`../whisk-challenge-dec26/`) → คนที่เล่นในร้านโพสต์ต่อได้ทันที

## 4) ทายหวานกี่กรัม (#ทายหวานHibi)
- **วิธีเล่น:** จิบแล้วทำหน้า → ให้คนดูทายในคอมเมนต์ว่าแก้วนี้หวานกี่กรัม (0 / 3 / 5 / 8 / 10 / 15) → เฉลยท้ายคลิป
- **ทำไมได้ผล:** คอมเมนต์เยอะ (ทุกคนอยากทาย) · ต่อยอดคลิป pain point P4

## 5) Holiday: ส่งมัทฉะให้คนพิเศษ (#ส่งความสดชื่น)
