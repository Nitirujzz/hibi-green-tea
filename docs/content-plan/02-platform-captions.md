## 1. ภาพรวมพฤติกรรมลูกค้าปัจจุบัน (2026) ที่ใช้ออกแบบแคปชัน

1. **ดูก่อน อ่านทีหลัง** — คนตัดสินใจจาก 1–3 วินาทีแรกของวิดีโอ / บรรทัดแรกของแคปชัน แคปชันมีหน้าที่ "ยืนยัน" สิ่งที่ภาพสื่อ
2. **ค้นในโซเชียลแทน Google** — คนพิมพ์ "มัทฉะ [ย่าน]" ใน TikTok/IG/Lemon8 → แคปชันต้องมี **keyword + ชื่อย่าน/สาขา** (Social SEO) ไม่ใช่แค่ hashtag
3. **Save = ตั้งใจจะไป** — คอนเทนต์ที่ถูก Save คือ intent สูง → ใส่ CTA "เซฟไว้ก่อนไป" ในโพสต์ความรู้/สาขา
4. **เบื่อโฆษณาตรง ๆ ชอบความจริงใจ** — เบื้องหลัง, ตอบคำถามจริง, เปิดต้นทุน ได้ผลกว่าการโปรโมตแบบใบปลิว
5. **คาแรกเตอร์ = ความผูกพัน** — คนติดตามตัวละคร ไม่ใช่โลโก้ → Capy ต้องมี "เสียง" ของตัวเอง

### Voice ของ Hibi-Capy (ใช้ทุกแพลตฟอร์ม ปรับระดับตามแพลตฟอร์ม)

| ทำ ✅ | ไม่ทำ ❌ |
|---|---|
| แทนตัวว่า **"Capy"** เรียกลูกค้าว่า **"เพื่อน ๆ"** หรือ **"ทุกคน"** | ใช้ "ท่าน", "ลูกค้าผู้มีอุปการคุณ" |
| ประโยคสั้น ใจเย็น ลงท้าย "นะ~", "เนอะ", "กันน้า" พอประมาณ | ลงท้ายซ้ำทุกประโยคจนน่ารำคาญ |
| ใช้คำญี่ปุ่นง่าย ๆ 1 คำ/โพสต์: *Oishii, Ganbatte, Hibi, Otsukare* | ญี่ปุ่นเยอะจนอ่านไม่ออก |
| Emoji หลัก: 🍵 🌿 ☁️ ♨️ 🍃 💚 (1–4 ตัว/โพสต์) + สติกเกอร์ Capy ในภาพ | Emoji รก ๆ เต็มบรรทัด, 🔥💯 สไตล์ขายตรง |
| รู้จริง เล่าแบบเพื่อน | ใช้ศัพท์เทคนิคโดยไม่อธิบาย |

> หมายเหตุ: ยังไม่มีอีโมจิคาปิบาร่าในมาตรฐาน Unicode → ใช้ **สติกเกอร์ Capy ของแบรนด์** ในภาพ/LINE แทน และเลี่ยงการใช้ 🦫 (บีเวอร์) แทนคาปิบาร่า
