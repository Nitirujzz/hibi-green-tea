## PART A — Master Visual Guideline (ใช้กับทุก Ads)

### A1. Color Palette (อิงจาก HIBI-BRAND-GUIDE.md ปรับโทนให้เป็น "คาเฟ่มัทฉะ")

| บทบาท | สี | HEX | ใช้กับ |
|---|---|---|---|
| Primary | Deep Matcha | `#16a34a` | Headline, ปุ่ม CTA, แถบแบรนด์ |
| Primary Light | Hibi Green | `#22c55e` | ไฮไลต์, ไอคอน (ใช้น้อย — ห้ามเป็นพื้นใหญ่ ดูนีออน) |
| Background | Tea Cream | `#fef7cd` | พื้นหลังหลักของงาน |
| Background 2 | Pearl White | `#f8fafc` | พื้นหลังงานความรู้ / Infographic |
| Earth | Clay Brown | `#92400e` | ตัวหนังสือรอง, Capy shading, เส้น |
| Accent | Premium Gold | `#fbbf24` | Badge ราคา/โปร, ดาว, "NEW" |
| Accent 2 | Copper | `#c2410c` | ป้าย Limited / ด่วน (ใช้ไม่เกิน 5% ของภาพ) |

**กฎ:** ไม่เกิน 3 สีหลักต่อชิ้น · สัดส่วน 60 (Cream/White) : 30 (Matcha) : 10 (Gold/Brown)

### A2. Typography
| ใช้กับ | ฟอนต์ไทย (เสนอ) | ฟอนต์อังกฤษ |
|---|---|---|
| Headline | **Kanit SemiBold / Bold** หรือ Prompt Bold | Inter Bold |
| Body | **IBM Plex Sans Thai / Sarabun** Regular | Inter Regular |
| ตัวเน้นญี่ปุ่น/ลายมือ | ลายมือแบรนด์ (ถ้ามี) สำหรับคำว่า "Hibi", "Oishii" | — |

- Headline ไม่เกิน **7 คำ** · ข้อความบนภาพรวมไม่เกิน **~20% ของพื้นที่**
- ขนาดขั้นต่ำบนมือถือ: Headline ≥ 64px, Body ≥ 32px (บนแคนวาส 1080px)

### A3. Hibi-Capy Character Guideline
| องค์ประกอบ | รายละเอียด |
|---|---|
| รูปร่าง | กลม ป้อม ตาเล็กปรือ ๆ (ชิล) จมูกใหญ่ ขาสั้น สีน้ำตาลอ่อน shading Clay Brown |
| อุปกรณ์ประจำตัว | **ถ้วยมัทฉะเล็กบนหัว** (แทนส้มยูซุที่คาปิบาร่าในญี่ปุ่นชอบมีบนหัว) |
| Expression Set (ต้องมีในไลบรารี) | ① Chill (ตาปรือ ยิ้มบาง) ② Happy (ตาโค้ง แก้มชมพู) ③ Sleepy/เหนื่อย ④ Surprised (ตาโต) ⑤ Sip (กำลังจิบ) ⑥ Onsen (แช่ในแก้วมัทฉะ ♨️) ⑦ Point (ชี้ไปที่ข้อความ/CTA) |
| Capy ประจำสาขา | Sensei (ฮาโอริ + ฉะเซ็น) · Family (+ลูก Capy) · Salaryman (เนคไท) · Student (แว่น+เป้) · Traveler (หมวก+กล้อง) |
| ตำแหน่งในภาพ | มุมล่าง/ข้าง กินพื้นที่ 15–30% · **มองหรือชี้ไปทางสินค้า/CTA** เสมอ เพื่อพาสายตา |
| ห้าม | ❌ บิดสัดส่วน ❌ เปลี่ยนสีตัว ❌ ทำท่าก้าวร้าว/เศร้าจริงจัง ❌ ถือของแบรนด์อื่น ❌ วางทับหน้าแก้วสินค้า |

### A4. Photography / Visual Style
- แสงธรรมชาติ นุ่ม โทนอุ่น · เห็น **เนื้อฟองมัทฉะ** และ **Layer นม-มัทฉะ** ชัด
- พร็อพ: ฉะเซ็น, ถ้วยเซรามิก, ไม้, ผ้าลินิน, ใบชา · ไม่ใช้พร็อพเกิน 3 ชิ้น
- Mix: **ภาพจริงสินค้า + Capy แบบ illustration** (Hybrid style) = ภาพจำหลักของแบรนด์

### A5. Size & Safe Zone

| Placement | ขนาด | Safe zone |
|---|---|---|
| Feed 4:5 (หลัก) | 1080×1350 | ขอบ 60px รอบด้าน |
| Feed 1:1 | 1080×1080 | ขอบ 60px |
| Story / Reels / TikTok 9:16 | 1080×1920 | **บนเว้น 250px, ล่างเว้น 340px**, ขวาเว้น 120px (ปุ่ม UI) |
| LINE Rich message | 1040×1040 | ปุ่ม CTA อยู่ครึ่งล่าง |
| LINE Rich menu | 2500×1686 (6 ช่อง) | — |
| GBP | 1200×900 (4:3) | หลีกเลี่ยงข้อความบนภาพ |
| Lemon8 cover | 1080×1440 (3:4) | หัวข้อในครึ่งบน |

### A6. File Naming & Delivery
```
HIBI_[CampaignCode]_[Branch/ALL]_[Placement]_[Version]_[YYMMDD]
ตัวอย่าง: HIBI_A3_BR2_Story_v1_261110.png
```
- ส่ง: PNG/JPG (ภาพนิ่ง) · MP4 H.264 ≤ 30MB (วิดีโอ) · ไฟล์ต้นฉบับ (.psd/.ai/.fig) · ซับไตเติลฝังในวิดีโอ (คนดูแบบปิดเสียง ~70%)
- ทุกวิดีโอมี **โลโก้ + Capy ภายใน 3 วินาทีแรก** และ **End card 1.5s** (โลโก้ + CTA)

## PART B — Campaign Overview

**Campaign:** "Every day, a little calm — ชิลทุกวันกับ Hibi"

| Code | ชื่อ Ad | Funnel | Objective (Meta/TikTok) | Audience | Budget share* |
|---|---|---|---|---|---|
| A1 | Meet Hibi-Capy | TOFU | Reach / Video views | Broad 18–40 รัศมี 7 กม. รอบ 5 สาขา, สนใจ คาเฟ่/มัทฉะ/ญี่ปุ่น | 25% |
| A2 | Menu Hero — Signature Drink | TOFU→MOFU | Engagement / Traffic | Interest คาเฟ่, ขนม, ชา + Lookalike ลูกค้า LINE | 20% |
| A3 | Branch Finder (×5 เวอร์ชัน) | BOFU | Store traffic / Traffic (Maps) | แยกรัศมี 3–5 กม. ต่อสาขา | 25% |
| A4 | Matcha 101 Carousel | MOFU | Engagement (Save) | Retarget: ดูวิดีโอ A1/A2 ≥ 50% | 10% |
| A5 | Add LINE รับคูปอง | BOFU | Leads / Messages (LINE) | Retarget: Engage IG/FB 30 วัน + เยี่ยมชมโปรไฟล์ | 15% |
| A6 | Loyalty — Stamp & Member | LOYALTY | Engagement / Message | Custom audience: LINE friends, ลูกค้าเดิม | 5% |

\* ปรับตามผลจริงทุก 2 สัปดาห์

**Retargeting Flow:** A1/A2 (ดู ≥ 50%) → A4 (Save/Engage) → A3 (ตามรัศมีสาขา) + A5 (LINE) → A6
